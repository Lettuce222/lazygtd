# Rust版: 旧仕様と動作確認

[旧 Hub 版仕様](https://github.com/Lettuce222/dotfiles/blob/79ca781c8be450078110501d7395730e0dc920bc/tools/lazygtd/SPEC.md)
は参照資料。実行に dotfiles、Hub、Orca、Go、gtd.py は不要。Rust + SQLite と、
ローカル優先、実サービスは明示的に選ぶという新しい決定を優先する。

## デモ（作りもののデータのみ）

1. `c` で作る。最初の行が題、`Ctrl+J` または端末が判別できる
   `Shift+Enter` で改行、`Enter` で保存。 `/` は表示中の箱を絞る。
2. `5` → `p` でステップ。 `c` で作る、`a` で既存IDをつなぐ、
   `J/K` で順序、`d` で外す、`x` で完了。最後の「次の行動」が
   終了すると、並びの先頭の予定が繰り上がる。レビュー中は先に進めない。
3. `6` で連絡待ち。 `t` は項目の情報、たとえば `follow_up=2026-11-25`、
   `who=依頼先`、`then=資料を確認`。期日・確認日が来たものは
   元の箱と「あなたの番」に表示。模擬レビューには `w` で両URLが
   閉じたというテスト結果を適用できる。実URLにはアクセスしない。
4. `4` → `j` で AI タスク。 `Enter` で右下の入力欄、`Ctrl+J` で
   改行、`Enter` で模擬送信。返信は同じ項目で読み、さらに指示できる。
   返事の未読と応答待ちは「窓口」にも表示。約0.8秒表示すると既読にする。
5. `!` で問い。 `j/k` で切り替え、番号で選ぶ。許可は180秒の期限が
   あり、承認と普通の返信は別。許可/承認を選んでも実行せず、ローカルに
   回答を記録するだけ。デモには4種類の問いがある。
6. `e` は本文の内蔵編集、`E` は外部エディタ、`o` は成果物
   （デモはサンプルの内容を表示）。Markdownの見出し・リスト・コード・
   URL・日本語幅を考慮した表は詳細で読み、`Ctrl+D/U` でスクロール。

## 仕事用DBの境界

- 本文とまだ形を試す情報は、検証したSQLite JSONに入れる。ID、revision、
  箱、担当、日時付きメッセージ、実行と参照関係は普通の列・テーブルに置く。
- 項目・関連・繰り上げ・実行と変更履歴はトランザクションにまとめる。
  SQLiteの版番号を上げる移行も同じトランザクション。v1からv6に移せる。
  古いアプリに戻すには更新前のバックアップを使う。旧Hubファイルは読み込まない。
- 設定なしの `Enter` はローカルの未送信キューまで。明示した
  `--agent-config PATH` 付きなら送信先・実行範囲・本文の確認後、
  `y` で選んだCodex/Claude Codeを起動する。全文が画面に収まらない
  場合はCLIの `agent-preview` / `agent-run ... --send` を使う。
  標準では追加指示は最近の会話を文脈に含む新しい実行。
  [セッション設定](agent-sessions.md)で、Codex / Claude Codeの正確なUUIDを指定して再開できる。
- `question-import JSON` と `question-reply` / `question-reason` は
  手元の連携口。この経路の登録・回答はローカルのみで、MCPやコマンドを許可しない。
  別の[Codex対話モード](approvals.md)では、実行中の要求に拒否または中断を返し、
  明示指定したメモだけ全文の確認後に一度だけ渡せる。
  機密の問いを登録する場合は `"hidden": true` とし、TUIとCLIの一覧・回答から除外する。
- `watch-resolve ID REV CLOSED_URL...` は、別途確かめた結果を渡す入口。
  確認が取れたURLが全件そろうまで同じ箱に置く。
  [GitHub監視の設定](pr-watch.md)を有効にした場合のみ、TUI稼働中に公開PRを自動確認する。
- エディタではSQLite本文のコピーを専用一時ファイルで編集し、保存時に
  revisionを照合する。 `LAZYGTD_EDITOR` / `EDITOR` は引数付きの
  シェル文字列ではなく実行ファイル名。成果物は特定DBの
  `<DB名>.assets/<タスクID>/` だけを開く。フォルダは自動作成しない。

## まだ試作外

TUIを閉じた後の常時監視、非公開・社内GitHubのPR監視、外部エージェントによる
コマンドや書き込みの許可、Claude Codeの対話承認、端末画面へのジャンプ、旧Hubデータの取り込み。
実CLIの起動や非認証エラーへの到達と、認証済みモデルの応答・実セッション再開は区別する。
